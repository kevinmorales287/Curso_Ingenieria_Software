# 📚 Apuntes LIS — UADY

En este repositorio encontrarás apuntes, notas de clase, ejercicios resueltos y videos de apoyo para las materias de la **Licenciatura en Ingeniería de Software** de la Facultad de Matemáticas, UADY. El contenido está organizado por semestre para que puedas encontrar fácilmente lo que necesitas.

---

## 📁 ¿Qué hay en cada carpeta?

Dentro de cada materia encontrarás:

```
materia/
├── notas/        → Apuntes por unidad en Markdown
├── ejercicios/   → Problemas resueltos y propuestos
├── videos.md     → Links a videos explicativos
└── referencias/  → Libros y recursos externos
```
